# Roadmap

Eight phases. Every phase ends with something real.

**Done means two things:** the box is ticked **and** the gate in
`quality/eval-gates.md` is passing. A ticked box with a failing gate is not done.

Progress: **Phases 0 and 1 complete. Phase 2 next.**

## Phase 1 — Data spine (weeks 2–3)

- [x] Verdict mapping and evidence policy, measured over the full corpus rather than taken from the API docs
- [x] CodeNet adapter — metadata ingest, 13,916,868 rows
- [x] Codeforces adapter — API, single global min-interval limiter at the documented 1 req / 2 s, resumable checkpointed cursor
- [x] Codeforces problemset snapshot — authoritative tags and population-level `solvedCount`
- [x] AtCoder — resolved, not blocked: DO NOT INGEST, recorded in `LEGAL.md` with the 2026-06-29 ToS revision as the decisive fact
- [x] Lake layout: raw → silver, idempotent partition replacement, with a files-on-disk versus files-read guard
- [x] PySpark normalisation to canonical schema
- [x] dbt project: staging and marts (`intermediate` deliberately empty — nothing yet needs a layer between)
- [x] SCD-2 shaped `dim_problem` and `dim_user`, built in SQL rather than via dbt snapshots; degenerate until a second collection lands
- [x] Custom tests: validity overlap, single-current, as-of correctness — plus corpus-coverage and key-ambiguity guards
- [x] Full corpus straight to 30M, no 5M staging step — the sample cutover was skipped because the guards that would have caught a sampling defect were built first
- [x] Observatory aggregates exported to committed JSON, with an allowlist that aborts on an unexpected column, a gate that reads only the written files, and a pre-commit hook that regenerates and byte-compares. The two gates are non-overlapping: a corrupted count passed the first and was caught only by the second
- [x] Airflow 3.3.0 on LocalExecutor — stage, dbt, publish. The crawl is deliberately absent: a twelve-hour rate-limited pass against a live judge does not belong on a schedule, and a permanently disabled task would imply a capability the pipeline does not have. Normalise is short-circuited on the landing zone against the last run report, so a routine trigger skips an hour of Spark and the skip is itself evidence. Tier 2: nothing in the free-stack ledger hosts a scheduler
- [x] Databricks notebook over the full corpus — three of the five observatory aggregates recomputed on a third engine from 23,607,105 fact rows and compared to the committed export, zero disagreements. No Codeforces handle exists in that workspace: the slice carries dense integer surrogates, because distinct counts are invariant under injective relabelling and a salted hash of a public handle list is reversible
- [x] G8 enforced in CI — `dbt build` runs on every push against synthetic fixtures generated by `scripts/make_ci_fixtures.py`, gating every data test except those that pin real-world counts, which carry the `real_data` tag and are excluded — the honest boundary of what CI proves. The excluded set is `dbt list --select tag:real_data`. Fixtures are invented rather than sampled, because a public repository is publication under `LEGAL.md`
- [x] First observatory charts — four, in the same notebook, with the activity chart carrying its left-truncation warning inside the figure rather than in a caption a screenshot would lose
